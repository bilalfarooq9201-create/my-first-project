# My First Streamlit Project

A tiny introductory Streamlit app that demonstrates a page title, text output, and a button interaction.

## Features

- Displays a welcome message.
- Shows a success message when the button is clicked.

## Requirements

- Python 3.10 or newer
- Streamlit

## Run locally

1. Clone this repository.
2. Open a terminal in the project folder.
3. Create and activate a virtual environment.
4. Install dependencies:

```bash
pip install -r requirements.txt
```

5. Start the app:

```bash
streamlit run APPP.py
```

Streamlit will print a local URL in the terminal. Open that URL in your browser.
